# Полный реестр тест-сценариев

Документ фиксирует полный список сценариев по ТЗ и текущую степень покрытия автотестами.

Формат каждого сценария:
- **Что проверяем** — суть проверки и входные условия.
- **Критерий успеха** — однозначный ожидаемый результат.
- **Статус** — `✅ Реализован`, `🟡 Частично`, `❌ Не реализован`.
- **Покрытие** — файл(ы) тестов.
